# Project Report – FitTrack Gym User Management System

**Project name:** FitTrack Gym User Management System  
**Running website URL:** http://localhost/gym_user_management_system/ (local demonstration URL; replace with the deployed URL if hosted online)

**Resources and tools used:** HTML5, CSS3, Bootstrap 5, JavaScript, PHP, MySQL, MySQLi, phpMyAdmin, XAMPP and GitHub.

**Main functionalities:**
- Member registration with name, username, email, password and membership plan.
- Secure login using hashed passwords and PHP sessions.
- Member dashboard showing membership plan, status and expiry date.
- Administrator dashboard to view, update and delete member records.
- MySQL database storage and retrieval for users and memberships.
- Form validation and responsive layout for desktop and mobile screens.

**Key success factors:**
- Simple and consistent user interface.
- Responsive Bootstrap layout.
- Separation of reusable PHP header, footer and configuration files.
- Database connectivity using MySQLi prepared statements.
- Different access permissions for administrators and members.

**Challenges or barriers faced:**
- Configuring the local PHP and MySQL environment.
- Connecting PHP pages to the MySQL database.
- Managing login sessions and protecting administrator pages.
- Testing form validation and database operations.
